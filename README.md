# Replay Highlight Tool

Công cụ quay source highlight từ replay PC Client Free Fire cho các giải đấu.

- Tải bản mới nhất ở mục **Releases**: file `ReplayHighlightSetup-<phiên bản>.exe`.
- Hướng dẫn sử dụng: file PDF đính kèm trong từng bản phát hành.
- Ứng dụng tự kiểm tra bản mới qua `latest.json` của bản phát hành mới nhất.
